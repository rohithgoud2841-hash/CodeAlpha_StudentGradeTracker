CodeAlpha Student Grade Tracker

Project Overview

The Student Grade Tracker is a Java console application developed as part of the CodeAlpha Java Programming Internship.

It helps users enter student names and marks, calculate average scores, identify the highest and lowest marks, and display a summary report.

Features

- Enter multiple student records.
- Validate student marks between 0 and 100.
- Calculate average marks.
- Identify the highest-scoring student.
- Identify the lowest-scoring student.
- Display a formatted student report.

Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Loops and conditional statements
- Exception handling

How to Run

1. Install the Java Development Kit (JDK), or open an online Java compiler.
2. Open "Main.java".
3. Copy the source code into the Java compiler.
4. Run the program and enter the student details.
5. View the generated report.
